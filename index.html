💊 MedCare Reachy

A Reachy Mini app that reminds at medication time, finds the patient, prompts each medicine, and watches each dose with its own camera. Intake tracking and emotion run on the robot; the MedAiCarePlus home server gets landmark points, emotion scores and two identity snapshots a second, and decides what is recorded.

Setup

  1. In the MedAiCarePlus web app: Settings → Reachy robot → Pair, and copy the robot key.
  2. On the server, set DEVICE_BIND to its home-network IP so the robot can reach port 8001.
  3. Install MedCare Reachy from the robot's dashboard, open its settings page, and enter the server address and robot key.

Limits

  • Needs a MedAiCarePlus server on your home network.
  • Cannot identify which pill was taken or how many; unverified doses go to a family member to confirm.
  • Not a medical device. Prototype; frame rate on a real robot not yet measured (below 12 fps, every dose goes to a family member to confirm). No microphone.
